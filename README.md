# BeeZee Toys — сайт

Сайт beezeetoys.ru: главная страница — живой дом-башня, где каждый этаж открывает раздел.

## Что где лежит

- `index.html` — вся страница: разметка, стили и анимации, данные разделов.
- `img/` — картинки: `house.webp` (дом), слои персонажей (`sortery-girl.webp`, `pressa-granny.webp`…), фото товаров.
- `.cpanel.yml` — инструкция для cPanel, куда копировать файлы при выкладке.

## Как выкладывается

1. Изменения попадают в ветку `main` этого репозитория.
2. В cPanel → **Git Version Control** → репозиторий → вкладка **Pull or Deploy**:
   - **Update from Remote** — забрать свежую версию с GitHub;
   - **Deploy HEAD Commit** — скопировать её в `public_html/beezeetoys.ru`.

## Как добавить персонажа

Кадры персонажа — PNG с прозрачным фоном, персонаж стоит на одном месте во всех кадрах.
Кадры склеиваются в одну полоску (`img/<комната>-<кто>.webp`), анимация задаётся в `index.html`.
